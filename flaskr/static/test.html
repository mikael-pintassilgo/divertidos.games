Make Resources Limited or Unlimited

This exercise is taken from the book Challenges for Game Designers by Brenda Brathwaite and Ian Schreiber. More information about this book can be found on the official website at https://designgames.wordpress.com/
For example, you could try making the resources in the game “Plants vs. Zombies” unlimited. This game has several types of resources, such as “Sunlight”, the lawn grid, cooldown time, and others.
Almost all of them can be found in the “Formal Elements Framework” list on this page: “Plants vs. Zombies”
